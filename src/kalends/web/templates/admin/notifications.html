Email

{% if 'email' in enabled %}On{% else %}Off{% endif %}

Sends from an email account you own. With Gmail, turn on 2-Step Verification and create an app password (Google Account › Security › App passwords); use smtp.gmail.com, port 587. Proton Mail needs its paid Bridge: running on this computer, use 127.0.0.1, the port and STARTTLS that Bridge shows, and Bridge's own username and password (not your Proton password). Kalends accepts the certificate a mail server on this computer makes for itself, and checks every other server's.

With email set up, people you share with can also choose email alerts (on an audience's Alerts tab).

Discord

{% if 'discord' in enabled %}On{% else %}Off{% endif %}

Posts in a channel of a server you manage: Channel settings › Integrations › Webhooks › New Webhook › Copy Webhook URL. A private channel just for you works well.
